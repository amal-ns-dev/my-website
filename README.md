# Amal NS Portfolio

A lightweight personal portfolio website built as a static HTML/CSS/JavaScript project with a code-editor inspired UI.

## Overview

This project presents a developer portfolio in a desktop-style workspace layout featuring:

- a left sidebar explorer
- tabbed content sections
- responsive mobile navigation
- a dark theme with terminal-like styling
- sections for home, about, contact, and experience
